# Student Management System (Next.js App Router)

ระบบจัดการข้อมูลนักศึกษา พร้อมระบบยืนยันตัวตนและการจัดการสิทธิ์ผู้ใช้งาน (RBAC) พัฒนาด้วย Next.js 15, Prisma ORM, SQLite และ NextAuth.v5

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Database:** SQLite + Prisma ORM
- **Authentication:** NextAuth.js (v5 Beta) - Credentials & GitHub OAuth
- **Styling:** Tailwind CSS
- **Validation:** Zod
